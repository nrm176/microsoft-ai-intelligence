# Microsoft AI Brief — 2026-10-08

## 要約
10月7日の主要な更新は、Microsoft Execution Containers (MXC) とGitHub Copilot local sandboxのGA、Copilot CLIのOllamaモデル発見機能、WindowsのHybrid Intelligence構想です。

## 1. MXCのGA
**事実:** エージェントのファイル・ネットワーク・UIアクセスを、エージェント自身が変更できないポリシーで制限します。Windows、macOS、Linuxで対応する隔離方式が異なります。Entraによるagent identity識別とIntuneの一部管理機能は今後提供予定です。
**重要性・分析:** プロンプト指示だけでなく、OS側で最小権限を強制できる点が重要。社内coding agentの実行権限分離に応用できます。
出典: https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/

## 2. GitHub Copilot local sandboxのGA
**事実:** Copilot CLI、Copilot app、VS Code Agent HostでGA。MXCを使い、エージェントのツール実行を制限します。企業管理ポリシーでの強制に対応し、追加料金なし。
**分析:** 対象repoだけの書込みを許すPoCと、禁止操作が遮断されるかのテストが有効です。
出典: https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/

## 3. Copilot CLIとOllama
**事実:** CLI 1.0.94-0から/modelで稼働中Ollamaのモデルを検出可能。tool callingとstreamingが必要。ローカルモデル選択はオフライン化を意味せず、CLIのoffline modeはCOPILOT_OFFLINE=trueを別途設定します。
**分析:** ローカル推論の導入摩擦が下がります。品質、速度、データ転送を実測すべきです。
出典: https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli/

## 4. Hybrid Intelligence
**事実:** HydraFusionのローカル/クラウドroutingは10月後半のexperimental preview予定。Copilotのlocal context/actions/modelsも今後数か月の段階的展開予定で、現時点のGAではありません。
**分析:** モデル選択とデータ境界を分離して評価する必要があります。
出典: https://blogs.windows.com/windowsexperience/2026/10/07/building-windows-for-hybrid-intelligence/
