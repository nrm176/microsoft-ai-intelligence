# Microsoft AI Brief — 2026-10-05

## 要約

前回以降、Work IQ、Fabric IQ、Microsoft Foundryについて前回内容を上書きする大型発表は確認できませんでした。今回は企業導入上重要な3点を記録します。

## 1. Microsoft 365 Copilot Plugin Registry

Microsoft Learnは、Declarative agent、Skill、Copilot connector、MCP serverをPluginとして組み合わせ、versioned packageとして登録・配布するモデルを整理しています。Plugin Registryは共有の登録・配布基盤であり、MCP serverなどの実行環境とは分離されます。

**なぜ重要か:** AgentやMCPが増えた際、公開、利用権限、バージョン、更新、廃止をPluginのライフサイクルとして管理できます。

**分析:** Pluginを配布・ガバナンス単位、MCP等を能力単位、AzureやDataverseを実行・データ単位として分離する設計がMicrosoft 365と整合しやすくなります。

一次情報: Microsoft Learn「What is a Microsoft 365 Copilot plugin?」

## 2. Copilot Home / Code / Autopilot と消費課金

MicrosoftはCopilotをHome、Code、Autopilotの統合体験へ再編しています。HomeはChatとCowork、Officeの作業起点、Codeは自然言語によるsolution building、Autopilotはクラウド上で継続的に動くAgentです。商用モデルではuser subscriptionとusage-based billingの併用、AI FinOpsによるコスト管理が示されています。

**なぜ重要か:** CopilotのTCOはseat costだけでなくagentic workloadのconsumption costを含めて管理する必要があります。

**分析:** 導入KPIもライセンス利用率だけでなく、Agent実行量、消費コスト、人手作業削減、業務成果へ拡張すべきです。

一次情報: Microsoft Source「New Microsoft Copilot Brings Home, Code, and Autopilot Together」、Microsoft Learn「September 2026 announcements」

## 3. Business Applications roadmap と MCP

Dynamics 365、Power Platform、Dataverseのロードマップ情報はAI at Work roadmapへ移行し、continuous roadmapへ移っています。Release Plannerは2026年11月15日に廃止予定です。ロードマップデータはMicrosoft Release Communications MCP Serverから取得できると案内されています。

**なぜ重要か:** Power Platform、Dataverse、Copilot Studioの変更監視を機械収集へ移せます。

**分析:** Microsoft AI BriefもWeb検索と構造化ロードマップ取得を併用すると、小規模な機能変更やリリース日変更の取りこぼしを減らせます。

一次情報: Microsoft Learn「September 2026 announcements」
