## 2. なぜ重要か

### Microsoft Copilot harness（未収録の重要発表）

**【事実】** Microsoft Copilot harnessはFoundry Agent ServiceでPublic Preview。再利用可能なSkills、MCPツール、サブエージェント、ソース管理可能な定義を組み合わせ、Microsoft管理のagent loopとsandboxで実行できます。Hosted Agentsの長時間実行耐障害性もGAです。中断後は元の入力から再起動するため、アプリ側で進捗保存と重複実行防止が必要です。

**【分析】** 社内の長時間エージェント処理に有力ですが、復旧が自動的に冪等性を保証するわけではありません。2026年12月1日からharness sandboxのCPU・メモリ従量課金が始まり、公式公表値は0.0994 USD/vCPU時、0.0118 USD/GiB時です。モデル推論や外部ツールの費用は別途発生し得ます。

### GitHub Copilotモデル廃止（期限の注意喚起）

**【事実】** 11月16日にClaude Opus 4.8、Claude Opus 5、GPT-5.6 Terraが廃止予定です。個人年間契約のClaude Opus 4.8は例外。推奨代替はClaude Opus 5.5、GPT-6.1 Sol、GPT-6 Lunaです。Business / Enterpriseで代替モデルの自動有効化を無効にしている場合は管理者設定が必要です。

**【分析】** モデル名を固定したCopilotの設定・ワークフローを確認すべきです。
