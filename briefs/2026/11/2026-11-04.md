# Microsoft AI Brief — 2026年11月4日

**要点:** GitHub CopilotのJetBrains Air統合、AIエージェント依存関係のDependabot更新、公開リポジトリのGitHub Actions保護変更を確認しました。Work IQ・Foundry IQ・Microsoft 365 Copilot・Copilot Studioについて、今回の調査で前回以降の独立した重要変更は確認できませんでした。

## 1. GitHub CopilotがJetBrains Airに対応（11月3日）

**何が変わったか【事実】** Agent Client Protocol（ACP）を使ってJetBrains AirからCopilotを選択し、IDE内またはAir Teamsのクラウド環境でコーディング作業を委譲できます。複数セッションの並行作業と差分レビューに対応します。

**なぜ重要か【分析】** PyCharmなどJetBrains IDEを使うチームにとって、既存のCopilot契約でエージェント作業を扱う選択肢が増えます。一方、Air側の利用分析にCopilot利用量は含まれず、Air側でCopilotの支出上限も設定できません。

**ユースケース【提案】** Pythonアプリのテスト追加・リファクタリングを別セッションで実行し、レビュー後に統合します。

**技術的示唆【事実と提案】** クラウドタスクは新規VM上のDockerコンテナで隔離実行。Air Teams対応組織、Copilot契約、管理者による有効化が必要です。個人・組織Copilotプランをタスク単位で選べない点を事前確認してください。

一次情報: https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air/

## 2. DependabotがAgent Package Managerに対応（11月3日）

**何が変わったか【事実】** `apm.yml`に宣言したGit依存関係をDependabotがバージョン更新し、存在する`apm.lock.yaml`を再生成します。github.comの全プランでGA。**セキュリティ更新には非対応**です。

**なぜ重要か【分析】** Skills・Prompts・Instructionsの依存関係をPRレビュー付きで更新でき、エージェントの変更管理をコード管理に近づけられます。

**ユースケース【提案】** 社内共通Skillsの定期更新PRを作成し、評価テスト合格後にマージします。

**技術的示唆【事実と提案】** `.github/dependabot.yml`に`apm`の対象ディレクトリと更新スケジュールを設定します。GHESは3.24で対応予定。更新PRの内容検証と実行テストは別途必要です。

一次情報: https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager/

## 3. GitHub Actionsのpull_request_target既定ブロック（11月2日発表）

**何が変わったか【事実】** 12月2日から公開リポジトリで`pull_request_target`を既定でブロックします。11月9日と16日の16:00–18:00 UTCに一時的な強制適用があります。非公開・内部リポジトリは対象外です。

**なぜ重要か【分析】** 外部PRからのシークレット流出リスクを下げますが、AIレビューや自動ラベル付けなど既存CIが停止する可能性があります。

**ユースケース【提案】** 公開リポジトリのAI関連ワークフローを棚卸しし、必要なものだけ例外許可します。

**技術的示唆【事実と提案】** GitHub Insightsのevaluate結果を確認し、例外はActions event policyで対象ワークフローに限定してください。

一次情報: https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2/
