## 1. Enterprise GitHub AppsでCopilot seatを管理

**何が変わったか【事実】** 11月10日、Enterprise GitHub Appsが企業レベルのCopilot seat management APIsを利用できるようになりました。新しい権限は`Enterprise Copilot license management`で、ユーザーとenterprise teamsへのseat割り当てを管理できます。

**なぜ重要か【分析】** ライセンス割り当てを個人トークン中心のスクリプトから、アプリ権限を使った運用に移せます。権限最小化、監査、運用担当者の交代に対応しやすくなります。

**ユースケース【提案】** 人事マスターやEntra IDの入退社・異動イベントに応じて、GitHub Copilotのseatを付与・回収し、月次棚卸しと費用配賦に活用します。

**技術的示唆【提案】** GitHub Appの権限を限定し、Azure Functions等で変更をオーケストレーションします。イベントの重複処理を防ぎ、操作履歴と承認ログを保存します。API対応はライセンス価格改定を意味しません。

## 2. Copilot CLI：MSBuild C++プロジェクトの解析設定を自動化

**何が変わったか【事実】** 11月10日、Microsoft C++ Language ServerにMSBuild compile commands extractorが同梱され、プロジェクトを開くと自動実行されるようになりました。以前必要だった`compile_commands.json`の手動作成や設定skillの探索を削減します。

**なぜ重要か【分析】** 大規模C++コードのシンボル解析や依存関係調査で、エージェントがコード理解を始めるまでの準備を短縮できる可能性があります。

**ユースケース【提案】** MSBuildを利用する既存C++業務アプリで、影響範囲調査、定義参照、改修レビューを支援します。

**技術的示唆【事実・提案】** CMake・独自ビルドでは引き続き`compile_commands.json`やskillが必要です。実プロジェクトで解析精度と処理時間を比較してください。

**一次情報：** [GitHub Changelog（2026-11-10）](https://github.blog/changelog/2026-11-10-c-language-server-now-auto-configures-msbuild-builds/)
