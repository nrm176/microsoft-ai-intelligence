対象期間：11月11〜16日朝 JST。前回以降の11月13日発表4件と未収録の11月11日発表1件。以下は一次情報に基づく事実と、社内DX向け分析・提案を分けて記載する。

## 1. Azure Content Understanding：GPT-6.1、GPT-6、GPT-5.6対応（11月11日・未収録）

**何が変わったか【事実】** 文書・テキスト・音声・動画のモデル選択肢を拡大。Microsoftの文書抽出評価ではGPT-6.1 Solを品質と費用のバランスがよい初期候補として推奨。GPT-6 Lunaは低コスト候補、GPT-6 Astraは高精度候補。評価では5件のラベル付き例でLunaの抽出精度が91.82%から94.16%に改善。

**なぜ重要か【分析】** 帳票処理で最高価格モデルを一律に使わず、誤抽出の業務影響と総費用でモデルを選択できる。

**ユースケース【提案】** 工事見積書の数量・金額抽出でSol、Luna、Astraを比較し、例示データの効果も測る。

**技術的示唆【事実・提案】** REST analyze要求の `modelDeployments` を差し替え、同一analyzer・スキーマ・入力で評価。リージョン、対応モデル、総費用を確認する。

## 2. Gemini 4 HydrogenがGitHub CopilotでGA（11月13日）

**何が変わったか【事実】** 高速なエージェント型コーディング向けモデルがIDE、CLI、Copilot SDK等に段階展開。従量課金はプロバイダー定価基準。Business/Enterpriseではモデルポリシーで制御可能。

**なぜ重要か【分析】** 小規模修正のコスト・速度最適化候補となるが、新モデルの既定有効化を管理する必要がある。

**ユースケース【提案】** Pythonのテスト生成と軽微な修正を既存モデルと比較。

**技術的示唆【提案】** 成功率、応答時間、料金、モデルポリシーを評価。

## 3. GitHub Copilot：6モデルを12月14日に廃止予定（11月13日）

**何が変わったか【事実】** Claude Fable 5、Claude Haiku 4.5、Gemini 3.8 Flash、Gemini 4 Argon、Grok 4.6、Kimi K3が対象。推奨代替は順にClaude Fable 5.2、Claude Haiku 5.5、Gemini 4 Hydrogen、Gemini 4 Carbon、Grok 4.7、Kimi K3は未発表。Claude Haiku 4.5は一部個人年間契約で例外。

**なぜ重要か【分析】** モデル固定の開発ワークフローが影響を受ける。

**ユースケース【提案】** Copilot CLI、IDE、SDKでモデル指定を棚卸し。

**技術的示唆【提案】** 12月14日までに代替モデルと企業モデルポリシーを検証。

## 4. GitHub Copilot app：GitHub Enterprise Server対応GA（11月13日）

**技術的示唆【提案】** クラウドセッション非対応を前提に運用を設計。

## 5. GitHub AI Scan：REST APIによる設定管理（11月13日・Public Preview）

**何が変わったか【事実】** 組織・リポジトリのAI Scan設定に `repository_scan` を追加。GET/PATCH APIで有効・無効を管理。設定を有効にしてもスキャンは自動実行されず、実行にはGitHub Code Security AI creditsを消費。GHES非対応。

**なぜ重要か【分析】** AIセキュリティ検査の適用範囲をコードで統制できる。

**ユースケース【提案】** 社内リポジトリのAI Scan設定を一括管理。

**技術的示唆【事実・提案】** `/orgs/{org}/code-scanning/ai-scan` と `/repos/{owner}/{repo}/code-scanning/ai-scan` を利用。企業ポリシーで禁止時は422。実行権限とAI credits予算を分離管理。
